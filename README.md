# TheThirdUmp

Landing page for the TheThirdUmp cricket analysis social media account (daily uploads on TikTok and Instagram).

Static site — no build step. Open `index.html` directly, or serve the folder:

```
python3 -m http.server 8000
```

## Structure

- `index.html` — page markup
- `css/style.css` — styling
- `js/script.js` — mobile nav toggle + footer year
- `assets/` — favicon

## Before publishing

The TikTok and Instagram links currently point to `@thethirdump` — update them in `index.html` if the actual handles differ.
